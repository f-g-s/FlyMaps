Google-API-Key benötigt

FlyMaps zeigt Googles Photorealistic 3D Tiles und nutzt die Geocoding API für Ortssuche und Standort-Banner. Dafür brauchst du einen eigenen API-Key. Er wird nur in deinem Browser gespeichert und direkt an Google gesendet.

  1. In der Google Cloud Console ein Projekt anlegen oder auswählen.
  2. Abrechnung aktivieren (ein Zahlungsmittel ist nötig). Google gewährt je API ein monatliches Gratis-Kontingent, die aktuellen Preise stehen in Googles Preisliste.
  3. Unter „APIs & Dienste → Bibliothek“ die Map Tiles API und die Geocoding API aktivieren.
  4. Unter „Anmeldedaten“ einen API-Key erstellen und ihn auf genau diese beiden APIs beschränken. Keine HTTP-Referrer-Beschränkung setzen, die Geocoding API unterstützt sie nicht.
  5. Empfohlen: In der Console für die Map Tiles API ein Tageslimit (Quota) setzen und einen Budget-Alarm anlegen, damit keine unerwarteten Kosten entstehen.
